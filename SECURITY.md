# Security policy

## Supported versions

Security fixes are provided for the latest released version of Dictation.

## Report a vulnerability

Please use GitHub's private **Report a vulnerability** form in the Security tab
of this repository. Do not disclose a vulnerability in a public issue.

Include the affected Dictation and Obsidian versions, operating system, impact,
and minimal reproduction steps. Never attach an API key, private recording, or
real vault content. Replace sensitive material with a synthetic example.

The report will be acknowledged as soon as practical. We will coordinate a fix
and disclosure with the reporter when the issue is confirmed.
